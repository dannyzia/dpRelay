# Secret-scan allowlist — one glob per line. `#` starts a comment; the comment
# is the justification and is required (a bare line with no reason is a smell,
# and the scanner exits 2 on one).
#
# A line here is a decision that a specific known value is safe to publish.
# Prefer tightening an allowlist entry over widening a pattern.
#
# Keep this list short. Every entry is a place a real credential could hide.

# Firebase CLIENT api keys (AIza…) in google-services.json. These are not
# server credentials: they are compiled into the APK and the web bundle by
# design and are only usable against allow-listed Android package names +
# SHA-1 fingerprints, enforced in the Google Cloud console, not in this file.
# The real secret for this project is the FCM_SERVICE_ACCOUNT_JSON private key,
# which is covered by the service-account patterns in secret-scan.sh.
google-services.json
authenticator-app/app/google-services.json

# Built dashboard output: a compiled copy of the web client, which embeds the
# client key above. Scanned by its own build step (npm run lint/build) instead.
web/dist/**

# The gate's own three files. They contain credential SHAPES (the detection
# patterns) rather than credentials, and two of their filenames trip the
# credential-shaped-filename rule. They ship and are reviewed alongside the
# gate itself, so excluding them here cannot hide a real key: removing this
# block fails the build until it is re-justified.
scripts/secret-scan.sh
scripts/filter-allowlist.cjs
scripts/secret-scan-allowlist.txt

# The gate's regression test. It MUST contain literal secret shapes — that is

server/test/secret-scan.test.ts
