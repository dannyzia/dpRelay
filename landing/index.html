What is dP Relay?

dP Relay is an SMS gateway with a REST API for OTP codes and bulk campaigns. Its main idea is simple: your own Android phone and SIM become the gateway, so messages go out from your number to any country the phone can reach, with no carrier contract to negotiate. Bangladesh is a special case: there, dP Relay also runs its own dedicated phone numbers on Grameenphone, Robi, Banglalink and Teletalk, so you can send without owning a device. Both use the same API.

Why use a phone-based SMS gateway

  1. Trust: your customers recognise you. A login code from an unknown or random number looks suspicious, and people hesitate to act on it. When the OTP arrives from your own number, it carries your identity, and customers are far more likely to trust it and enter the code.
  2. Attention: your promotions get noticed. Messages from typical bulk-sender IDs blend into the pile, and customers learn to scroll past them. A promotion sent from your own number stands out as a message from someone they know.

    Marketing messages usually need the recipient's opt-in; say so here.

  3. Deliverability: you don't look like a bulk sender. Phones and SMS apps often flag or block numbers known for bulk sending as spam. Your own SIM isn't a bulk sender to your customers, so your messages are less likely to be filtered out before anyone sees them, as long as you send at a normal pace.
  4. Right-sized cost: no big packages up front. Many bulk SMS providers sell packages of thousands of messages, far more than an app needs in its early days. Here you start with 20 free messages and buy only what you will actually use.
  5. Local reach: a local number for customers in their home country. Customers who live abroad or in another country usually get messages from an unfamiliar international number. Put a phone with a local SIM in their country and they get a message from a local number. dP Relay charges only $0.0015 per message for the gateway, and the SMS itself goes out on your local plan, so you avoid international SMS rates. For example, Twilio's published price for one SMS to Bangladesh is $0.5962 plus possible carrier fees, while our Bangladesh numbers charge ৳0.20 per message (about $0.0017 at roughly ৳120 to the dollar; check today's rate).

Where it fits less well

Phone-based gateways suit steady, moderate volume. For very large bursts or guaranteed uptime, a carrier-grade provider is the safer choice, because one phone's power, connection and carrier limits set the ceiling.

How it works

  1. Create your app.

    Sign up, verify your email and register an app. Your appId and appSecret are shown once, so store them safely.

  2. Choose a gateway.

    Enroll your own Android phone from the dashboard. To send to Bangladesh, you can use our dedicated numbers instead, with nothing to install.

  3. Send and verify.

    Call POST /v5/otp/send from your backend, then POST /v5/otp/verify with the code your user typed. Launch bulk campaigns from the dashboard.

Send and verify in two calls

Replace [your-api-domain] with your API base URL.

API=https://[your-api-domain]

# 1) Send the code
curl -X POST "$API/v5/otp/send" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: $APP_ID" \
  -H "X-App-Secret: $APP_SECRET" \
  -d '{"phone":"+8801XXXXXXXXX"}'

# 2) Verify what the user typed
curl -X POST "$API/v5/otp/verify" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: $APP_ID" \
  -H "X-App-Secret: $APP_SECRET" \
  -d '{"phone":"+8801XXXXXXXXX","otp":"123456"}'
const API = "https://[your-api-domain]";
const headers = {
  "Content-Type": "application/json",
  "X-App-Id": APP_ID,
  "X-App-Secret": APP_SECRET,
};

// 1) Send the code
await fetch(`${API}/v5/otp/send`, {
  method: "POST",
  headers,
  body: JSON.stringify({ phone: "+8801XXXXXXXXX" }),
});

// 2) Verify what the user typed
const res = await fetch(`${API}/v5/otp/verify`, {
  method: "POST",
  headers,
  body: JSON.stringify({ phone: "+8801XXXXXXXXX", otp: "123456" }),
});
console.log(await res.json()); // { ok: true, verified: true }
import requests

API = "https://[your-api-domain]"
H = {"X-App-Id": APP_ID, "X-App-Secret": APP_SECRET}

# 1) Send the code
requests.post(f"{API}/v5/otp/send", headers=H, json={"phone": "+8801XXXXXXXXX"})

# 2) Verify what the user typed
r = requests.post(f"{API}/v5/otp/verify", headers=H,
                  json={"phone": "+8801XXXXXXXXX", "otp": "123456"})
print(r.json())  # {'ok': True, 'verified': True}
